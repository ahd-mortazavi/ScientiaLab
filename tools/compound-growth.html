Educational tool only. Assumes a constant return compounded monthly, with contributions at the end of each month. Real markets never return a constant rate — this is an illustration, not a forecast or advice, and ignores fees and taxes.

How it works

r = annual return ÷ 12, n = years × 12 lump sum = initial × (1 + r)ⁿ contributions = monthly × ((1 + r)ⁿ − 1) ÷ r

Future value is the two added together. At a 0% return it is simply everything you put in.
